# Evommune

> Evommune, Inc. (Nasdaq: EVMN) is a clinical-stage biopharmaceutical company in Palo Alto, California, developing therapies that target the key drivers of chronic inflammatory disease. Evommune publishes no public API, no developer portal and no machine-readable API contract; this file exists so an agent can reach the company's real public surface without inventing one.

## API surface

- [No public API](https://www.evommune.com/): Probed 2026-08-12. No OpenAPI, GraphQL, MCP server, AsyncAPI or A2A agent card is published on any Evommune host, and every /.well-known/ path returns 404. The marketing site runs WordPress and serves the stock WordPress REST API at /wp-json/, which is default CMS infrastructure rather than a product API.
